This is a Library Management System made to help manage
books, students, issuing and returning books.

# FEATURES

- Add books
- Remove books
- Search for books
- Issue books
- Return books
- Manage students

# Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

# How to Run LMS

1. Download or clone this repository.
2. Install the required libraries.
3. Go to  app.py file in your respective coding platform.
4. Run the new terminal and write "python app.py" there.
5. Copy the local host address after running it
6. Open it in your browser.
